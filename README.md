# Automação de Cadastro de Produtos

Projeto de automação desenvolvido com Python e PyAutoGUI para cadastro automático de produtos em sistema web utilizando dados de uma planilha CSV.

## Tecnologias
- Python
- PyAutoGUI
- Pandas

## Funcionalidades
- Login automático
- Leitura de planilha CSV
- Cadastro automático de produtos
- Automação de navegação
